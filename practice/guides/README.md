# Учебники по статическим сайтам и публикации

Этот раздел содержит крупные учебники для студентов по трем темам:
- Hugo: создание и организация контента, конфигурация, мультиязычность.
- GitHub Pages: публикация статических сайтов и настройка источника.
- GitHub Actions: автоматизация сборки и деплоя.

## Карта учебников

1. `hugo.md` — полное руководство по Hugo, структуре контента и практикам работы в этом репозитории.
2. `github-pages.md` — все про GitHub Pages, типы сайтов, публикацию и проверку деплоя.
3. `github-actions.md` — подробный учебник по YAML‑workflow и автоматизации.
4. `multilingual.md` — отдельный разбор многоязычности в текущем проекте (RU/EN, структура, меню, URL).
5. `hugo-templates.md` — подробный учебник по языку шаблонов Hugo с примерами и ссылками на лучшие гайды.

## Как использовать

1. Изучите `hugo.md`, чтобы понимать структуру сайта и правила контента.
2. Перейдите к `github-pages.md`, чтобы настроить публикацию.
3. Закрепите материал через `github-actions.md`, разобрав workflow по шагам.
4. Для поддержки RU/EN структуры используйте `multilingual.md` как техническую памятку.
5. Для работы с шаблонами и расширением оформления изучите `hugo-templates.md`.
