# Чек‑лист сдачи

1. Репозиторий создан на GitHub и имеет корректное название для выбранного типа Pages.
2. Hugo‑сайт создаётся и запускается локально (`hugo server`).
3. В проекте есть минимум 3 опубликованных страницы/поста.
4. В `hugo.toml` выставлен корректный `baseURL`.
5. Добавлен конфиг кэша изображений через `cacheDir`.
6. В `.github/workflows/` лежит workflow для деплоя.
7. В `Settings → Pages` выбран `Source: GitHub Actions`.
8. GitHub Actions успешно завершает сборку и деплой.
9. Сайт доступен по URL GitHub Pages.
10. В истории минимум 4 осмысленных коммита.
